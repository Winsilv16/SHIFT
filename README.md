# SHIFT - 1º Encontro de UX no IFRN

Atividade de Design Web. Projeto desenvolvido para apresentar o evento **SHIFT**, o primeiro encontro de UX realizado no IFRN.

O site possui múltiplas páginas com informações sobre:
- evento
- programação
- palestrantes
- inscrições
- organização
- contato

---

# Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts

# Funcionalidades

- Layout moderno e responsivo
- Menu de navegação entre páginas
- Página de programação do evento
- Formulário de inscrição
- Cards de palestrantes
- Responsividade para dispositivos móveis
- Efeitos visuais com hover
- Grid responsivo para palestrantes
